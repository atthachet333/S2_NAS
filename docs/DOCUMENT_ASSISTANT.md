# ผู้ช่วยเอกสาร (F21)

ผู้ช่วยเอกสารตอบจากข้อความของ ResourceVersion ปัจจุบันที่ผู้ใช้ภายในมีสิทธิ์เปิดเท่านั้น รองรับขอบเขต `CURRENT_RESOURCE`, `SELECTED_RESOURCES` (สูงสุด 20 ไฟล์) และ `AUTHORIZED_LIBRARY` โดยแสดงขอบเขตให้เห็นก่อนเริ่มสนทนา

## การใช้งาน

- เปิด Details ของไฟล์แล้วเลือก **ถามเกี่ยวกับเอกสาร**
- เลือกไฟล์หลายรายการใน Files แล้วเลือก **ถาม AI**
- เลือกขอบเขตคลังเอกสารเพื่อถามข้ามเอกสารที่เข้าถึงได้
- คำถามต่อเนื่องใช้ประวัติล่าสุดไม่เกิน 6 ข้อความและค้นหลักฐานใหม่ทุกครั้ง
- Citation เปิดทรัพยากรด้วย Resource ID; ไม่มี path หรือ storage key ใน API

คำตอบเป็นข้อความล้วนใน UI จึงไม่มี HTML/script จากโมเดล การคัดลอกคัดลอกเฉพาะคำตอบที่มองเห็น ไม่รวม metadata ซ่อนเร้น ระบบไม่ทำงานเขียนต่อเอกสาร ไม่ย้าย เปลี่ยนชื่อ แชร์ ลบ หรือส่งข้อมูลออกระบบอื่น

F21 ใช้ non-streaming generation เพื่อคง atomicity ของข้อความและ citation; stop/regenerate และ export ถูกเลื่อนไว้ ข้อความสนทนาเป็นข้อมูลส่วนบุคคลของผู้ใช้และลบ thread ได้

## ขอบเขตผลิตภัณฑ์

Portal และ public share ไม่มี assistant route ผู้ใช้ `EXTERNAL` ถูกปฏิเสธโดย `requireInternal` ก่อนเข้า service ส่วน Google-synced file ใช้ข้อความที่สกัดและทำดัชนีใน NAS เท่านั้น ไม่เรียก Google ระหว่างตอบ
