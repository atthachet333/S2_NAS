# คลังเอกสาร

## คลังไม่ใช่ถังขยะ

| | คลัง | ถังขยะ |
|---|---|---|
| เจตนา | เก็บรักษาไว้ | ตั้งใจจะทิ้ง |
| ฟิลด์ | `lifecycleState = ARCHIVED` | `deletedAt` |
| ค้นหาเจอไหม | ✅ เจอ | ❌ ไม่เจอ |
| จะถูกลบเองไหม | ❌ ไม่มีวัน | ✅ เมื่อครบอายุ |
| เปิด/ดาวน์โหลดได้ไหม | ✅ ได้ | ต้องกู้คืนก่อน |

ใช้ฟิลด์คนละตัวโดยเจตนา ถ้าใช้ฟิลด์เดียวกัน เอกสารที่ตั้งใจเก็บไว้สิบปีจะถูกงาน
เก็บกวาดถังขยะลบทิ้งวันหนึ่ง

## สิ่งที่ไม่เปลี่ยนเลย

การเก็บเข้าคลัง **ไม่แตะ**:

- ไบต์ของไฟล์ และ checksum
- ประวัติเวอร์ชันทั้งหมด
- ผู้ดูแล
- แท็กและประเภทเอกสาร
- ดัชนีค้นหา (รวมข้อความจาก OCR และที่ตรวจแก้แล้ว)
- สิทธิ์การเข้าถึงของผู้ใช้ภายใน

สิ่งเดียวที่เปลี่ยนคือ `lifecycleState` พร้อมเวลาและผู้ที่กด

## ที่ไหนบ้างที่ซ่อน

| ที่ | เห็นเอกสารในคลังไหม |
|---|---|
| ไดร์ฟของฉัน / ไดร์ฟของระบบ | ❌ ซ่อน (เปิดได้ด้วย `includeArchived`) |
| ล่าสุด | ❌ ซ่อน |
| การค้นหา | ✅ **เห็น** |
| มุมมอง "คลังเอกสาร" | ✅ เห็น |
| พื้นที่ลูกค้า | ❌ ซ่อนเสมอ |

**การค้นหาต้องหาเจอเสมอ** ผู้ใช้ที่พิมพ์ชื่อเอกสารแล้วไม่เจอเพราะมันถูกเก็บเข้าคลัง
จะสรุปว่าเอกสารหายไป และไปสร้างใหม่ซ้ำ - การซ่อนจากการค้นหาสร้างปัญหามากกว่าที่แก้

ส่วนการ "ไม่เกะกะ" เป็นเรื่องของหน้าเรียกดู ไม่ใช่ของการค้นหา

## พื้นที่ลูกค้า

เอกสารที่เก็บเข้าคลัง **หายไปจากพื้นที่ลูกค้าทั้งหมด** ทั้งการเรียกดูและการค้นหาลึก

การเก็บเข้าคลังเป็นการตัดสินใจภายในว่างานชิ้นนั้นจบแล้ว ลูกค้าไม่จำเป็นต้องเห็น
สถานะการทำงานภายในขององค์กร

ถ้าอนาคตมีความต้องการทางธุรกิจให้ลูกค้าเห็นคลังด้วย ต้องเพิ่มอย่างตั้งใจภายหลัง

## สิทธิ์

ใช้ **สิทธิ์แก้ไขเอกสาร** - ผู้ที่แก้ไขเอกสารได้ย่อมจัดระเบียบมันได้

ไม่ใช้สิทธิ์ระดับผู้ดูแล เพราะการเก็บเข้าคลังไม่ทำลายอะไร และย้อนกลับได้ทันที
การบังคับให้ต้องรอผู้ดูแลจะทำให้ไม่มีใครใช้ และพื้นที่ทำงานจะรกเหมือนเดิม

## Legal Hold ไม่ขวางการเก็บเข้าคลัง

คลังคือการรักษา ไม่ใช่การทำลาย การห้ามเก็บเข้าคลังขณะถูกระงับการลบ
จะไม่ได้ปกป้องอะไรเพิ่ม แต่ทำให้จัดระเบียบเอกสารที่อยู่ระหว่างตรวจสอบไม่ได้

## คลังเอกสารกับลิงก์แชร์ภายนอก (F18)

**เอกสารในคลังสร้างลิงก์แชร์ใหม่ไม่ได้** ต้องนำออกจากคลังก่อน

**ลิงก์เดิมที่ชี้ไปยังเอกสารที่ถูกเก็บเข้าคลังจะใช้ไม่ได้ทันที** และไม่มีการบันทึกว่าถูกยกเลิก
ถ้านำออกจากคลัง ลิงก์ที่ยังไม่หมดอายุและไม่ถูกยกเลิกจะกลับมาใช้ได้อีก

เหตุผล: F16 ซ่อนเอกสารในคลังจากพื้นที่ลูกค้าอยู่แล้ว การเปิดให้แขกเข้าถึงต่อ
จะทำให้ "เก็บเข้าคลัง" มีความหมายต่างกันสองแบบสำหรับคนนอกสองกลุ่ม

โฟลเดอร์แม่ที่ถูกเก็บเข้าคลังทำให้ทั้งกิ่งหายจากสายตาแขก ไม่ใช่แค่ตัวโฟลเดอร์นั้น
