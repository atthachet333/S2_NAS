# ประเภทเอกสาร

## การจัดประเภทเป็นการตัดสินใจของคน

F15 **ไม่มีการจัดประเภทอัตโนมัติ** และไม่มี AI

การเดาผิดในเอกสารการเงินมีราคาสูงกว่าการให้คนเลือกเองมาก - ใบกำกับภาษีที่ถูกจัดเป็น
ใบเสร็จจะหาไม่เจอตอนที่ต้องใช้จริง และไม่มีใครรู้ว่ามันถูกจัดผิดจนกว่าจะสาย

## ตั้งค่าได้ ไม่ใช่ enum ตายตัว

ประเภทเอกสารของแต่ละองค์กรต่างกัน และการเพิ่มประเภทใหม่ไม่ควรต้องแก้โค้ดแล้ว deploy ใหม่

```
DocumentCategory
  id · name · slug · isActive · sortOrder
```

`Resource.documentCategoryId` เป็น nullable - `null` แปลว่า **ยังไม่ได้จัดประเภท**
ไม่ใช่ "ไม่มีประเภท"

## slug ไม่เปลี่ยนตามชื่อ

เปลี่ยนชื่อที่แสดงได้ แต่ `slug` คงเดิม

`slug` ถูกใช้ใน URL และในชุดค้นหาที่บันทึกไว้ การเปลี่ยนมันตามชื่อจะทำให้ลิงก์และ
ชุดค้นหาที่คนบันทึกไว้เสียทันทีที่มีคนแก้คำผิดในชื่อ

ชื่อประเภทเป็นภาษาไทยเกือบทั้งหมด ซึ่งแปลงเป็น ASCII slug ไม่ได้อย่างมีความหมาย
จึงคงอักษรไทยไว้และตัดเฉพาะอักขระที่ใช้ใน URL ไม่ได้ออก

## ปิดการใช้งานแทนการลบ

ประเภทที่ยังมีเอกสารอ้างถึง **ลบไม่ได้** ระบบตอบ `CATEGORY_IN_USE` พร้อมจำนวนเอกสาร

การลบทิ้งทั้งที่ยังมีคนใช้จะทำให้เอกสารหลายร้อยฉบับสูญเสียการจัดประเภทที่คนนั่งทำไว้
ซึ่งกู้กลับไม่ได้

ประเภทที่ปิดอยู่ไม่แสดงในตัวเลือกของผู้ใช้ทั่วไป แต่เอกสารที่เคยผูกไว้ยังผูกอยู่

## ประเภทเริ่มต้น

มีให้หกรายการและ **สร้างเมื่อผู้ดูแลกดเท่านั้น** ไม่ใช่ seed อัตโนมัติ

```
ใบกำกับภาษี · ใบเสร็จรับเงิน · สัญญา · งบการเงิน · เอกสารภาษี · เอกสารลูกค้า
```

จงใจให้มีน้อย การใส่มาสามสิบประเภทจะทำให้ไม่มีใครหาอันที่ต้องการเจอ และคนจะเลิกจัดประเภทไปเลย

ทำงานซ้ำได้โดยไม่สร้างของซ้ำ - ตรวจจาก slug ก่อนสร้างเสมอ

## สิทธิ์

| การกระทำ | ใครทำได้ |
|---|---|
| ดูรายการประเภท | ผู้ใช้ภายในทุกคน |
| กำหนดประเภทให้เอกสาร | ผู้ที่แก้ไขเอกสารนั้นได้ |
| สร้าง / เปลี่ยนชื่อ / ปิด / ลบ | ผู้ดูแลระบบ |

**ผู้ใช้ภายนอกจัดประเภทไม่ได้** และเส้นทางจัดการทั้งหมดอยู่หลัง `requireInternal`

## ใช้เป็นตัวกรอง

ประเภทเอกสารเป็นตัวกรองในการค้นหา และมีมุมมองอัจฉริยะ "ยังไม่ระบุประเภทเอกสาร"
สำหรับตามเก็บของที่ตกหล่น

## การเก็บรักษา

ทั้งตัวประเภทและการผูกกับเอกสารเป็นข้อมูลที่คนสร้าง จึงอยู่ในชุดสำรองเสมอ
และการซ้อมกู้คืนตรวจว่าทั้งสองอย่างกลับมาครบ ดู [RESTORE.md](RESTORE.md)
